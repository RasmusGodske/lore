# Shared Agent Knowledge Base — Specification

A self-hosted, git-backed knowledge base for a small team that AI agents read from and
write to through sandboxed sessions. The filesystem is the source of truth; git is the merge and
audit mechanism; containers provide isolation.

This spec set is written to be buildable from scratch by someone with no context on the
discussions that produced it.

## Reading order

Read `00` first. `01` through `03` describe the runtime. `04` describes what agents and
humans actually call. `05` describes what lives inside the repository and is largely
independent of the rest — it could be adopted on its own.

## Status

Design specification with a first implementation in progress; the decisions recorded here
were settled 2026-09-03. Code lives in the same repo as this spec, as an npm workspace:
`packages/server` (the NestJS orchestrator), `packages/cli` (the `kb` client),
`sandbox/Dockerfile`, `seed/` (initial knowledge repo contents), `docker-compose.yml`, and
`openapi.json` at the root, generated by the server and committed (see `01-architecture.md`).

**Scope of the first build:** the minimal slice described in these documents, running
locally under `runc` — sessions, sandboxed exec, git smart HTTP with the pre-receive hook,
SQLite state and audit, bearer-token auth, HTTP API, MCP and the `kb` CLI. No web UI, no TLS, no warm
pool, no GitHub mirror, no VM deployment yet.

Sections marked **OPEN** are unresolved decisions that need a call before or during
implementation.
